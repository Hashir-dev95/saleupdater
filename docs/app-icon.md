# Sales Updater app icon

`assets/images/app-icon.png` is the new launcher icon and web favicon. It uses a
white document, rising bars, and an upward sales arrow on emerald green. The
small text and third-party logos from the earlier icon are omitted for legibility.

The opaque square artwork has a compact central mark with generous space around
it for Android adaptive masks. The same full-bleed image is the adaptive foreground
over an emerald background. Expo generates the required native image sizes.
The previous image assets remain available. The native splash is unchanged.

Created using the built-in image generation tool with this prompt:

> Use case: logo-brand. Create the finished production launcher icon asset for an existing mobile business application named Sales Updater. The app helps salespeople update Excel from WhatsApp sales messages; its brand is emerald green. Deliver one square 1024x1024 opaque PNG icon, edge-to-edge solid deep emerald #047857 background, absolutely no transparency, no outer padding/border and no pre-rounded app tile corners. Center one beautifully drawn compact white geometric mark: a minimal folded-corner spreadsheet/document with three rising sales bars integrated with a simple upward-right arrow. The symbol should be unified, elegant, bold, immediately legible at 32px, with clean consistent strokes and generous negative space. Flat vector-like precision; sophisticated contemporary business/finance app feel. Entire white symbol must stay within the central circular safe area of diameter 60% of the canvas, approximately 48% canvas width and 50% height, for Android adaptive circle/squircle cropping. Keep background solid all the way to every edge so this same icon can be used as adaptive foreground over a matching emerald background. No lettering, no Sales Updater words, no tagline, no X or Excel logo, no WhatsApp logo, no decorative gloss, no shadows, no gradient, no 3D, no mockup, no extra objects. Output the actual icon asset only.
